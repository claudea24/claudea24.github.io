# claudea24.github.io

Personal website for Claudea Jennefer — live at https://claudea24.github.io

Plain HTML/CSS/JS (no build step), so GitHub Pages serves it as-is.

- `index.html` — home page (intro + contact)
- `projects.html` — projects page
- `assets/css/style.css` — styles (Google Sites–inspired)
- `assets/js/main.js` — nav shadow + scroll fade-in
- `assets/img/` — project images

Preview locally: `python3 -m http.server` then open http://localhost:8000
